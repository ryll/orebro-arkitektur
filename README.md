# Örebro Arkitektur

An Android app about the architecture of Örebro, Sweden. Built in 2013 as my
*gymnasiearbete* — the final project of Swedish upper-secondary school.

The app presents a set of notable Örebro buildings: a browsable list, a short
description page per building with photo, a Google Maps satellite view with
markers, and a page on the city's history. Content is in Swedish.

Written in Java for Android (minSdk 11 / targetSdk 17) in Eclipse with the ADT
plugin, using the v4 support library and Google Play Services for maps.

It never got past prototype. The project was a collaboration: another student was
writing the actual guide — the building descriptions and history text — for me to
build into the app. That half was never finished, so the content never arrived.
What's here is the shell waiting for it: one building page fully built out, the
rest placeholder screens, and some copy still lorem ipsum.

Archived here as-is, unchanged since 2013 — including the beginner-grade code.
